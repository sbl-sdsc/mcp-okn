# Diabetes — intermediate data

The intermediate data tables for the Type 2 diabetes case study are **not
included here because of their large size**.

Every other file the study produced is in the parent folder
([`docs/examples/Diabetes/`](../)) — the report, literature comparison,
reproducibility record, results workbook, `figures/`, and `scripts/`. The data
tables that would live in this folder can be regenerated by re-running the
analysis with the [`okn-bioanalysis`](../../../../skills/okn-bioanalysis/) and
[`okn-report-style`](../../../../skills/okn-report-style/) skills, or read
directly from the `Diabetes_results.xlsx` workbook in the parent folder.
