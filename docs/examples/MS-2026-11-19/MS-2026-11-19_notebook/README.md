# Multiple Sclerosis — an integrative multi-knowledge-graph map

Re-runnable study: 50 SPARQL queries over `ubergraph`, `spoke-okn`, `rdkg`, `prokn`, `digcfdekg`, `oard-kg`, `biomarkerkg`, `gene-expression-atlas-okn`, `wikidata`, `biohealth`, `nde`, `nestkg`, run 2026-11-19 by claude-opus-5-5. Generated by mcp-okn v0.6.3 (build c0dab53).

## Run it

With [uv](https://docs.astral.sh/uv/), from this folder (it builds the environment from `requirements.txt`):

```bash
cd /path/to/MS-2026-11-19_notebook
uv run --with jupyterlab --with-requirements requirements.txt jupyter lab MS-2026-11-19_notebook.ipynb
```

Then choose **Run → Run All Cells**. The query cells load the cached rows. To rerun the study from scratch against the live endpoint, uncomment `# RERUN = True` in the setup cell (or start with `OKN_RERUN=1`). To rerun every query live without opening Jupyter, writing a copy with the new results:

```bash
cd /path/to/MS-2026-11-19_notebook
OKN_RERUN=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to notebook --execute --output MS-2026-11-19_notebook-rerun.ipynb MS-2026-11-19_notebook.ipynb
```

To render the executed notebook (from the cached rows) as a self-contained HTML page beside it, for reading or sharing without Jupyter:

```bash
cd /path/to/MS-2026-11-19_notebook
PYTHONDONTWRITEBYTECODE=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to html --execute --embed-images --output MS-2026-11-19_notebook.html MS-2026-11-19_notebook.ipynb
```

Without uv: `pip install -r requirements.txt jupyterlab`, then `jupyter lab MS-2026-11-19_notebook.ipynb` from this folder.

## Caveats

- The cached rows are what the endpoint returned when the study ran. The graphs are redeployed from time to time, so a live re-run can differ; `verify_all()` reports which queries changed.
- Some queries returned more rows than the session log keeps; their cache holds the first rows only (see `cached_rows` in `queries/manifest.json`). `RERUN = True` fetches every row.
- Figures are the images the study produced; re-running the analysis cells regenerates them only if those cells write them.
