# Spaceflight-Induced Bone Loss: an Integrative Cross-Knowledge-Graph Study

Re-runnable study: 31 SPARQL queries over `spoke-genelab`, `rdkg`, `digcfdekg`, `prokn`, `babel`, `ubergraph`, `spoke-okn`, `biomarkerkg`, run 2026-11-19 by claude-opus-5-5. Generated by mcp-okn v0.6.3 (build eca1374).

## Run it

With [uv](https://docs.astral.sh/uv/), from this folder (it builds the environment from `requirements.txt`):

```bash
cd /path/to/Spaceflight-Bone-Loss_notebook
uv run --with jupyterlab --with-requirements requirements.txt jupyter lab Spaceflight-Bone-Loss_notebook.ipynb
```

Then choose **Run → Run All Cells**. The query cells load the cached rows. To rerun the study from scratch against the live endpoint, uncomment `# RERUN = True` in the setup cell (or start with `OKN_RERUN=1`). To rerun every query live without opening Jupyter, writing a copy with the new results:

```bash
cd /path/to/Spaceflight-Bone-Loss_notebook
OKN_RERUN=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to notebook --execute --output Spaceflight-Bone-Loss_notebook-rerun.ipynb Spaceflight-Bone-Loss_notebook.ipynb
```

To render the executed notebook (from the cached rows) as a self-contained HTML page beside it, for reading or sharing without Jupyter:

```bash
cd /path/to/Spaceflight-Bone-Loss_notebook
PYTHONDONTWRITEBYTECODE=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to html --template-file okn_notebook.html.j2 --execute --embed-images --output Spaceflight-Bone-Loss_notebook.html Spaceflight-Bone-Loss_notebook.ipynb
```

Without uv: `pip install -r requirements.txt jupyterlab`, then `jupyter lab Spaceflight-Bone-Loss_notebook.ipynb` from this folder.

## Contents

- `Spaceflight-Bone-Loss_notebook.ipynb`: the notebook (provenance, one cell per query, analysis)
- `Spaceflight-Bone-Loss_notebook.html`: the executed notebook as one self-contained page, when it has been rendered (see above). View it in a browser; JupyterLab's HTML viewer blocks scripts until you click **Trust HTML**, so interactive maps and charts stay blank there
- `okn_sparql.py`: `run_query()` / `verify_all()`; needs only pandas
- `okn_notebook.html.j2`: the HTML page's template; it folds long code cells
- `queries/`: each query verbatim (`qNN.rq`), the text actually sent when the server rewrote it (`sent/qNN.rq`), and `manifest.json`
- `data/`: the rows each query returned during the session
- `analysis.py`: the study's analysis helpers (signatures, enrichment, tiers, modules)
- `okn_figstyle.py`: report figure style (from the okn-report-style skill)
- `mechanistic_map.py`: mechanistic-map renderer (from the okn-bioanalysis skill)
- `requirements.txt`

## Caveats

- The cached rows are what the endpoint returned when the study ran. The graphs are redeployed from time to time, so a live re-run can differ; `verify_all()` reports which queries changed (row count or values) and which graphs were redeployed.
