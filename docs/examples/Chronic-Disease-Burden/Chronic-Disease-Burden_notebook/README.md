# Chronic-Disease Burden in US Counties (spoke-okn CDC PLACES + County Health Rankings)

Re-runnable study: 20 SPARQL queries over `spoke-okn`, `ubergraph`, run 2026-11-18 by claude-opus-5-5. Generated by mcp-okn v0.6.3 (build c09ddbd).

## Run it

With [uv](https://docs.astral.sh/uv/), from this folder (it builds the environment from `requirements.txt`):

```bash
cd /path/to/Chronic-Disease-Burden_notebook
uv run --with jupyterlab --with-requirements requirements.txt jupyter lab Chronic-Disease-Burden_notebook.ipynb
```

Then choose **Run → Run All Cells**. The query cells load the cached rows. To rerun the study from scratch against the live endpoint, uncomment `# RERUN = True` in the setup cell (or start with `OKN_RERUN=1`). To rerun every query live without opening Jupyter, writing a copy with the new results:

```bash
cd /path/to/Chronic-Disease-Burden_notebook
OKN_RERUN=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to notebook --execute --output Chronic-Disease-Burden_notebook-rerun.ipynb Chronic-Disease-Burden_notebook.ipynb
```

To render the executed notebook (from the cached rows) as a self-contained HTML page beside it, for reading or sharing without Jupyter:

```bash
cd /path/to/Chronic-Disease-Burden_notebook
PYTHONDONTWRITEBYTECODE=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to html --template-file okn_notebook.html.j2 --execute --embed-images --output Chronic-Disease-Burden_notebook.html Chronic-Disease-Burden_notebook.ipynb
```

Without uv: `pip install -r requirements.txt jupyterlab`, then `jupyter lab Chronic-Disease-Burden_notebook.ipynb` from this folder.

## Contents

- `Chronic-Disease-Burden_notebook.ipynb`: the notebook (provenance, one cell per query, analysis)
- `Chronic-Disease-Burden_notebook.html`: the executed notebook as one self-contained page, when it has been rendered (see above). View it in a browser; JupyterLab's HTML viewer blocks scripts until you click **Trust HTML**, so interactive maps and charts stay blank there
- `okn_sparql.py`: `run_query()` / `verify_all()`; needs only pandas
- `okn_notebook.html.j2`: the HTML page's template; it folds long code cells
- `queries/`: each query verbatim (`qNN.rq`), the text actually sent when the server rewrote it (`sent/qNN.rq`), and `manifest.json`
- `data/`: the rows each query returned during the session
- `analysis.py`

## Caveats

- The cached rows are what the endpoint returned when the study ran. The graphs are redeployed from time to time, so a live re-run can differ; `verify_all()` reports which queries changed (row count or values) and which graphs were redeployed.
- Figures are the images the study produced; re-running the analysis cells regenerates them only if those cells write them.
