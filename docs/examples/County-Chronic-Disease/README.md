# US County Chronic Disease Burden (OKN)

Re-runnable study: 11 SPARQL queries over `spoke-okn`, `ruralkg`, run 2026-11-18 by claude-opus-5-5. Generated by mcp-okn v0.6.3 (build 2a4a1ef).

## Run it

With [uv](https://docs.astral.sh/uv/), from this folder (it builds the environment from `requirements.txt`):

```bash
cd /path/to/county-chronic-disease-2026-11-18-2
uv run --with jupyterlab --with-requirements requirements.txt jupyter lab county-chronic-disease-2026-11-18-2.ipynb
```

Then choose **Run → Run All Cells**. The query cells load the cached rows; set `RERUN = True` in the setup cell (or start with `OKN_RERUN=1`) to query the live endpoint instead. To rerun every query live without opening Jupyter, writing a copy with the new results:

```bash
cd /path/to/county-chronic-disease-2026-11-18-2
OKN_RERUN=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to notebook --execute --output county-chronic-disease-2026-11-18-2-rerun.ipynb county-chronic-disease-2026-11-18-2.ipynb
```

To render the executed notebook (from the cached rows) as a self-contained HTML page beside it, for reading or sharing without Jupyter:

```bash
cd /path/to/county-chronic-disease-2026-11-18-2
PYTHONDONTWRITEBYTECODE=1 uv run --with nbconvert --with ipykernel --with-requirements requirements.txt jupyter nbconvert --to html --execute --embed-images --output county-chronic-disease-2026-11-18-2.html county-chronic-disease-2026-11-18-2.ipynb
```

Without uv: `pip install -r requirements.txt jupyterlab`, then `jupyter lab county-chronic-disease-2026-11-18-2.ipynb` from this folder.

## Caveats

- The cached rows are what the endpoint returned when the study ran. The graphs are redeployed from time to time, so a live re-run can differ; `verify_all()` reports which queries changed.
- Figures are the images the study produced; re-running the analysis cells regenerates them only if those cells write them.

## Analysis files (added after generation)

- `analysis.py` — all analysis logic (assembly, validation, composite scores, correlations, confounders, Moran's I, maps, workbook); imported by the notebook
