**Why this answers the question.** This is the only variant crosswalk in the federation that reaches a **protein residue**. V01 and V03 tell you a variant is shared; V02 tells you *what it does to which protein*. Every row above names the exact substitution (P72H, R20Q, D285H) and ProKN's curated interpretation — somatic vs germline, benign vs uncertain significance, and in one case a **protective** effect.

The protein ranking is a checklist of hereditary-cancer and mismatch-repair genes — TP53, BRCA1/2, MLH1, MSH2, MSH6, ATM, VHL, CDKN2A, NF1, TSC2 — which is where clinical variant testing and UniProt's variant curation both concentrate. TP53 alone contributes 343 of the shared variants.

**Read the interpretations, not just the match.** rs10254120 (PMS2 R20Q) is annotated *benign, normal mismatch-repair activity* despite appearing in a Lynch-syndrome context, and rs1045485 (CASP8 D285H) is *protective*. A shared rsID says the two graphs are talking about the same variant — ProKN's prose says whether it matters and in which direction, which no count can convey.

**Extraction limit.** The regex takes the last rsID when a description names two; that is 43 of 70,416 descriptions (0.06%).

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX schema: <http://schema.org/>

SELECT ?variantLabel ?rs ?proknDescription WHERE {
  GRAPH <https://purl.org/okn/frink/kg/prokn> {
    ?v a up:Natural_Variant_Annotation ; schema:description ?d ; rdfs:label ?variantLabel .
