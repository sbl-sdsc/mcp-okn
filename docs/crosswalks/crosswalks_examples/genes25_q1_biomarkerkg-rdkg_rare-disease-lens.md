**Why this answers the question — and the answer is a warning.** The premise of the question was that the diseases would differ: a gene causal in a *rare* disease being repurposed as a marker for a *common* one. What the data shows is different. RDKG's `related_to` edges are extremely broad — PON1, a serum paraoxonase measured as a cardiovascular and organophosphate-exposure marker, is related to 111 RDKG diseases that include acoustic neuroma, ALS, anaplastic astrocytoma, angiocentric glioma, anxiety disorder, acute coronary syndrome and arteriolosclerosis. That is not a rare-disease gene panel; it is a literature co-mention graph.

So the honest reading: **`related_to` measures how much a gene has been studied, not what it causes.** The genes at the top of this table (TP53, TNF, IL6, KRAS, EGFR) are the most-studied genes in biomedicine, which is exactly why they are also the ones with clinical assays.

**Where the join does carry causal weight** is the second column. RDKG's `has_gene` edges from ClinVar variants are specific: **TP53 (14 variants), BRAF (3), KRAS (1)** and nothing for the cytokines. That column separates *genes with catalogued pathogenic variation* from *genes that are merely much discussed* — and it is the one to use when asking whether a biomarker gene has rare-disease genetics behind it.

**Caveats.** (1) `related_to` is an association of mixed provenance; treat it as breadth of literature, not causation. (2) The ClinVar variant counts are what RDKG carries, not all of ClinVar. (3) Note the IRI form: RDKG uses `identifiers.org/ncbigene/`, not the `ncbi.nlm.nih.gov/gene/` form the rest of the Entrez cluster uses — joining with the wrong form returns zero rows silently.

```sparql
PREFIX obo: <http://purl.obolibrary.org/obo/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX blv: <https://w3id.org/biolink/vocab/>
SELECT ?geneSymbol (COUNT(DISTINCT ?rareDisease) AS ?rdkgRareDiseases)
       (COUNT(DISTINCT ?clinvarVariant) AS ?clinvarVariants) WHERE {
  { SELECT DISTINCT ?ez WHERE {
      GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
        VALUES ?bp { obo:OBCI_1000009 obo:OBCI_1000015 obo:OBCI_1000016 obo:OBCI_1000017 }
        ?s ?bp ?g . FILTER(STRSTARTS(STR(?g),'https://pubchem.ncbi.nlm.nih.gov/rest/rdf/gene/GID')) }
      BIND(REPLACE(STR(?g),'^.*/gene/GID','') AS ?ez) } }
  BIND(IRI(CONCAT('http://identifiers.org/ncbigene/',?ez)) AS ?gr)
  GRAPH <https://purl.org/okn/frink/kg/rdkg> {
    ?gr rdfs:label ?geneSymbol .
    OPTIONAL { ?gr blv:related_to ?rareDisease }
    OPTIONAL { ?clinvarVariant blv:has_gene ?gr }
  }
} GROUP BY ?geneSymbol ORDER BY DESC(?rdkgRareDiseases) LIMIT 14
```
