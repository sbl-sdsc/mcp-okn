```
FILTER(STRSTARTS(STR(?mp),'…/HAS_MARKER_GENE_IN'))
```

leaving `?mp` unbound across every reified statement in ProKN and testing each predicate as a string. Enumerating the predicate first shows there are only **three** of them — `HAS_MARKER_GENE_IN_KIDNEY` (485 statements), `_LIVER` (225) and `_HEART` (200) — so the scan becomes a three-row `VALUES` list, which also carries the tissue name without the `REPLACE` that was extracting it from the IRI. This is the third variant of one pattern in this corpus: **a string test against a predicate or literal is a lookup written so the engine cannot use its index.** Enumerate the small set once, then bind it.

**Why the join is required.** ProKN curates *which* genes mark a cell type in a given tissue but holds no expression measurement; GXA holds single-cell differential expression keyed on the CL cell type but does not know which genes are canonical markers. Only the CL join asks "is the curated marker actually differentially expressed where GXA measured it?"

**Why this answers the question.** Every marker is the right one for its cell type: **IL7R, PTPRC (CD45), ITK, THEMIS, BCL11B and CAMK4** are canonical T-cell genes; **MS4A6A and F13A1** are macrophage markers; **DCN** (decorin) is the classic fibroblast marker; and the hepatocyte entries — **CYP2E1, APOA2, APOC1** — are liver-specific drug-metabolism and apolipoprotein genes. Two independent resources, one curated and one measured, agree on cell identity.

**Read the sign carefully.** Every log2FC in the table is **negative**, which does not mean these markers are absent. GXA's contrasts here are cell-type-versus-background within a tissue, and the direction depends on which side of the comparison the cell type sits; the magnitude and the extreme p-values are what indicate a strong, cell-type-restricted signal. Treating −6.5 for F13A1 as "macrophages lack F13A1" would invert the biology.

**One coverage caution.** ProKN's marker curation exists for exactly three tissues, so this crosswalk cannot say anything about the rest of the body. The heart dominates the table (11 cell types, 107 markers) partly because it has the most curated markers, not because cardiac cell types are better characterised in GXA.
