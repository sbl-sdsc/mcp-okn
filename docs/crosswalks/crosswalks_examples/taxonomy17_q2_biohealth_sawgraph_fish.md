**Why this answers the question — and where the two graphs disagree about what matters.** For a species in both, BioHealthKG supplies a genuine second exposure axis: *Micropterus salmoides* carries **Aeromonas hydrophila** (a zoonotic fish pathogen) and a species-specific rhabdovirus; *Oncorhynchus mykiss* adds *Aeromonas salmonicida* and **Anisakis simplex**, the nematode behind anisakiasis in undercooked fish. So a largemouth bass with 213 PFOS measurements is also a documented host for a bacterium and a virus — two independent reasons the same fillet is a health question.

**But the overlap is poor, and in a specific way.** The species SAWGraph measures most heavily are barely represented in BioHealthKG: **bluegill (419 measurements) has no BioHealthKG record at all**, nor does black crappie (245) or northern pike (128). Conversely BioHealthKG's best-covered fish, **rainbow trout (77 assertions)**, is not in SAWGraph's top twelve for PFOS, and *Cyprinus carpio* and *Salmo trutta* (34 each) appear only because they are laboratory and aquaculture models. BioHealthKG's coverage tracks **biomedical literature volume**; SAWGraph's tracks **state fish-consumption advisories**. They intersect on the handful of species that are both eaten and studied.

**Two cautions.** The `interacts_with` objects include container terms — `Fishes`, `Bacteria`, `Parasites`, `Animal Model`, `Animals, Laboratory` — that carry no species-specific information, so the assertion counts overstate the useful content. And the join is a **bare Latin-binomial string match** with no shared identifier; it happens to be reliable here because both graphs use accepted binomials, but a synonym or authority string on either side would silently miss.

```sparql
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX coso: <http://w3id.org/coso/v1/contaminoso#>
SELECT ?species (COUNT(DISTINCT ?m) AS ?pfosMeasurements) WHERE {
  GRAPH <https://purl.org/okn/frink/kg/sawgraph> {
    ?mtp rdfs:label ?species .
    FILTER(CONTAINS(STR(?mtp),'biologicalTaxon'))
    ?s coso:sampleOfMaterialType ?mtp .
    ?m coso:analyzedSample ?s ; coso:ofSubstance ?sub .
    ?sub rdfs:label "Perfluorooctanesulfonic acid" .
  }
} GROUP BY ?species ORDER BY DESC(?pfosMeasurements) LIMIT 12
```
