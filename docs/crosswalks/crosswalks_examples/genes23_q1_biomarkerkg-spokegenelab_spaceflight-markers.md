Crosswalk: biomarkerkg × spoke-genelab on Entrez. BiomarkerKG's gene analytes are PubChem gene IRIs whose GID is the Entrez id; spoke-genelab mints genes as `http://www.ncbi.nlm.nih.gov/gene/{entrez}` and hangs NASA GeneLab differential-expression measurements off them.

Research question: are the genes used as clinical biomarkers on Earth measured in spaceflight assays — and which ones most?

**Why this answers the question.** The genes at the top are not random: **CD40** and **CCL2** (immune activation and monocyte recruitment), **TGFB1** (fibrosis and tissue remodelling), **S1PR1** (lymphocyte egress), **IFITM3** (interferon response) and **APOE** (lipid transport) are the axes spaceflight physiology is *about* — immune dysregulation, fluid and lipid shifts, tissue remodelling. That these are also the analytes clinicians measure on Earth is the point of the join: it identifies markers with an existing clinical assay **and** a spaceflight measurement history, which is the shortlist for crew health monitoring.

**What the join buys.** BiomarkerKG knows a gene is clinically measurable but nothing about microgravity; spoke-genelab knows a gene was measured in flight but nothing about its clinical marker status. Only the Entrez join produces "clinically established *and* flight-characterised".

**Caveats — important here.** (1) The counts are **assays that measured the gene**, not assays where it changed significantly, and not spaceflight-vs-ground contrasts. A high count reflects platform coverage (the gene is on the array / in the RNA-seq panel) as much as biology. (2) For a real spaceflight effect you must restrict to clean Space Flight vs Ground Control contrasts with matched covariates — use `get_valid_contrasts(tissue=, include_confounded=)`; of 680 SF-vs-GC assays only 188 are covariate-clean. (3) Labels here are spoke-genelab's descriptive gene names, not HGNC symbols.

PREFIX obo: <http://purl.obolibrary.org/obo/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX gl: <https://purl.org/okn/frink/kg/spoke-genelab/schema/>
SELECT ?geneSymbol (COUNT(DISTINCT ?assay) AS ?spaceflightAssaysMeasuringIt) WHERE {
  { SELECT DISTINCT ?ez WHERE {
      GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
        VALUES ?bp { obo:OBCI_1000009 obo:OBCI_1000015 obo:OBCI_1000016 obo:OBCI_1000017 }
        ?s ?bp ?g . FILTER(STRSTARTS(STR(?g),'https://pubchem.ncbi.nlm.nih.gov/rest/rdf/gene/GID')) }
      BIND(REPLACE(STR(?g),'^.*/gene/GID','') AS ?ez) } }
  BIND(IRI(CONCAT('http://www.ncbi.nlm.nih.gov/gene/',?ez)) AS ?gg)
  GRAPH <https://purl.org/okn/frink/kg/spoke-genelab> {
    ?assay gl:MEASURED_DIFFERENTIAL_EXPRESSION_ASmMG ?gg .
    ?gg rdfs:label ?geneSymbol .
  }
} GROUP BY ?geneSymbol ORDER BY DESC(?spaceflightAssaysMeasuringIt) LIMIT 15
