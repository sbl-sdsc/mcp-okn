**Why the join is required, and what changed.** SPOKE holds disease→gene associations keyed on DOID with no variants; BiomarkerKB holds specific dbSNP variant entries keyed on disease with no association evidence. The pairing only exists across both.

biomarkerkg has migrated its disease axis to MONDO, so `DOID_9256` and `DOID_10283` now have 0 triples there and the join must bridge spoke-okn(DOID) → ubergraph `skos:exactMatch` → biomarkerkg(MONDO). The 2026-06-27 version queried biomarkerkg on DOID directly and silently returned nothing.

**The gene pairing is derived.** BiomarkerKB encodes the gene inside each variant record's `rdfs:label` (`... sequence variation in gene APC/NCBI:324`); extracting the symbol and equating it to SPOKE's gene label produces a real gene-level join. The earlier version hard-coded seven `(DOID, gene, rsID)` triples, so it could only echo pairs already chosen by hand.

**Why this answers the question.** Both lists reconstruct the recognised hereditary panels for their disease, which is the evidence that the derived join works.

Colorectal returns the **polyposis and Lynch-syndrome architecture**: `APC` (familial adenomatous polyposis), the mismatch-repair genes `MLH1`/`MLH3`, `AXIN2` and `TGFBR2` in Wnt and TGF-β signalling, and `BUB1B` (mosaic variegated aneuploidy). The two genes at the top, **POLE and POLD1**, are the polymerase-proofreading-associated polyposis genes — and their variant counts (4,793 and 2,482) dwarf everything else, which is characteristic of proofreading-domain screening producing very large rare-variant catalogues.

Prostate returns **HOXB13** first — the best-established rare high-penetrance prostate susceptibility gene — followed by `SPOP`, `RNASEL` and `ELAC2` (the classic linkage-era prostate loci), the androgen receptor `AR`, and the DNA-repair genes `CHEK2`/`BRCA2` that drive current PARP-inhibitor eligibility.

**The cross-disease comparison repeats the ascertainment lesson.** Colorectal has *fewer* shared genes than prostate (42 vs 60) but **7.6× more variants** (10,293 vs 1,353), because two colorectal genes are under exhaustive sequencing while the prostate entries are spread more evenly. **CHEK2 appears in both lists** — 40 colorectal variants, 77 prostate — a genuine pleiotropic DNA-damage-response gene rather than an artefact of the join. As in the breast/RA pair, the variant count reflects how a gene is screened, not how strongly it is associated.

```sparql
PREFIX sschema: <https://purl.org/okn/frink/kg/spoke-okn/schema/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?diseaseLabel (COUNT(DISTINCT ?geneSym) AS ?genesInBoth) (COUNT(DISTINCT ?rsid) AS ?biomarkerVariants) WHERE {
  VALUES ?doid { <http://purl.obolibrary.org/obo/DOID_9256> <http://purl.obolibrary.org/obo/DOID_10283> }
  GRAPH <https://purl.org/okn/frink/kg/spoke-okn> {
    ?doid rdfs:label ?diseaseLabel ; sschema:ASSOCIATES_DaG ?gene .
    ?gene rdfs:label ?geneSym .
  }
  GRAPH <https://purl.org/okn/frink/kg/ubergraph> {
    ?mondo skos:exactMatch ?doid .
    FILTER(STRSTARTS(STR(?mondo),'http://purl.obolibrary.org/obo/MONDO_'))
  }
  GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
    ?b <http://purl.obolibrary.org/obo/OBCI_1000008> ?mondo ;
       <http://purl.obolibrary.org/obo/OBCI_1000016> ?variant ;
       rdfs:label ?bLabel .
  }
  FILTER(CONTAINS(?bLabel,'in gene '))
  BIND(REPLACE(?bLabel,'^.*in gene ([^/]+)/NCBI:.*$','$1') AS ?bmGene)
  BIND(REPLACE(STR(?variant),'^.*/snp/','') AS ?rsid)
  FILTER(?bmGene = ?geneSym)
} GROUP BY ?diseaseLabel
```
