Research question: which clinical biomarker genes carry a CFDE gene-trait association, and what traits are they?

**Why this answers the question.** The trait side is the informative one, and it is emphatically **immune and inflammatory**: Crohn's, IBD, multiple sclerosis, atopic dermatitis and eczema, allergic disease, autoimmune thyroid disease, childhood asthma. BiomarkerKG's gene analytes are dominated by cytokines and inflammatory mediators (IL6, TNF, TGFB1), so CFDE's inferences place them exactly where immunology would: the same genes recur across a family of immune-mediated conditions.

Two entries sit outside that pattern and are worth noting — **hypertension** (37 genes) and **waist circumference** (30) are cardiometabolic traits reached through the same marker panel, which is what you would expect from APOE, VEGFA and TGFB1 being in the analyte set.

**What the join buys.** BiomarkerKG asserts a marker–disease pair curated from the literature; CFDE REVEAL infers gene–trait links computationally from large-scale data. Joining them lets you ask whether a curated clinical claim is corroborated by an independent inference — and, in the other direction, which CFDE traits are already covered by an existing clinical assay.

**Caveats.** (1) CFDE trait counts are *inferences at scale*, not curated disease associations — TP53's 1,042 traits is a statement about how pleiotropic the inference makes it, not about clinical utility. (2) Trait labels come from ubergraph and mix HP phenotypes with EFO/MONDO diseases and quantitative traits, so "trait" here is broader than "disease". (3) Adding a second `OPTIONAL` (gene sets) to the per-gene query made the endpoint cancel the sort; keep such queries to one aggregate at a time.

PREFIX obo: <http://purl.obolibrary.org/obo/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX dig: <https://purl.org/okn/frink/kg/digcfdekg/schema/>
SELECT ?geneSymbol (COUNT(DISTINCT ?trait) AS ?cfdeTraits) WHERE {
  { SELECT DISTINCT ?ez WHERE {
      GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
        VALUES ?bp { obo:OBCI_1000009 obo:OBCI_1000015 obo:OBCI_1000016 obo:OBCI_1000017 }
        ?s ?bp ?g . FILTER(STRSTARTS(STR(?g),'https://pubchem.ncbi.nlm.nih.gov/rest/rdf/gene/GID')) }
      BIND(REPLACE(STR(?g),'^.*/gene/GID','') AS ?ez) } }
  BIND(IRI(CONCAT('http://www.ncbi.nlm.nih.gov/gene/',?ez)) AS ?gg)
  GRAPH <https://purl.org/okn/frink/kg/digcfdekg> {
