That number matters for planning an analysis: it means a NeST-driven question can be answered against ProKN's annotation with essentially no attrition, so any gap you see in a result is a gap in *annotation depth*, not in the join.

| Other | MT-ND4 (mitochondrially encoded), IFNA13 (one of 13 near-identical IFN-alpha genes), ARL17B, VNN3 |

**Why they miss.** These are the entries where UniProt-level curation is thinnest: uncharacterised reading frames, and segmental-duplication families (NPIP, GOLGA6L, NUTM2, POTE, IFNA) whose members are near-identical in sequence and are routinely collapsed or filtered by downstream resources. NeST retains them because it is built from an interaction network that scores them independently; ProKN does not carry them because there is little curated protein-level knowledge to carry.

**Practical read:** the join is safe to treat as complete for any functional question. The one place to be careful is a paralogue-family analysis — if a question turns on NPIP, GOLGA6L, NUTM2 or IFN-alpha family members specifically, the ProKN side will be silent, and that silence is a curation gap rather than a biological negative.
