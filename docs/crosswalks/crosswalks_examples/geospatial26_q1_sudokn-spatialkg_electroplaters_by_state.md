🧠 **Assistant**

**A broken IRI construction, and the predicate that makes it unnecessary.** The earlier version of this query reached a company's site by *building* the IRI — `REPLACE(company,'-company-instance$','') + '-geosite-1-instance'`. SUDOKN's site IRIs now end **`-geolocation-1-instance`**, so every constructed IRI missed and the query returned 0 rows without erroring.

The fix is not to patch the string. SUDOKN publishes an explicit predicate, **`s:organizationLocatedIn`**, that links a company to its site directly — 652 of the 652 NAICS-332813 companies have one. Traversing the edge instead of reconstructing the identifier is both correct today and immune to the next suffix change. The NAICS leg was never broken: the escaped classifier IRI `NAICS%20332813-individual` still matches all 652 companies.

**Why the join is required.** SUDOKN knows which companies describe themselves as electroplaters and where they sit, but nothing about regulatory status. FIOKG carries EPA FRS facilities with their own NAICS assignment and a KWG region IRI, but no manufacturer directory. SPATIALKG supplies the GADM state whose FIPS turns the EPA region code back into a state name, which is the only way the two industry counts land in the same rows.

**Why this answers the question.** The two sources agree on *where* electroplating happens and disagree systematically on *how much*. Ohio and Michigan lead both — the Great Lakes metal-finishing corridor — and the industrial Midwest plus Texas dominates either ranking. That agreement is what makes the join trustworthy.

But **SUDOKN captures only about 17% of the EPA-registered establishments** (652 of 3,874), and the shortfall is uneven. Pennsylvania is comparatively well covered (52 of 115, 45%), while Tennessee (20 of 124, 16%) and New York (39 of 189, 21%) are thin. That is expected rather than wrong: SUDOKN is a self-reported directory of small and medium manufacturers, and EPA FRS is a regulatory census that every permitted facility must appear in regardless of size or willingness to be listed. The ratio is a **directory-coverage measure**, not a discrepancy in the underlying industry.

**One structural caution.** The EPA leg counts facilities and the SUDOKN leg counts companies, and a company may operate several facilities — so part of the 6× gap is unit mismatch, not coverage. The `OPTIONAL` on the EPA subquery also means a state SUDOKN knows but the EPA region parse does not reach would show a blank rather than a zero; none of the top 12 is affected, but a longer listing should not read a blank as "no facilities".

PREFIX s: <http://asu.edu/semantics/SUDOKN/>
PREFIX frs: <http://w3id.org/fio/v1/epa-frs#>
PREFIX kwgo: <http://stko-kwg.geog.ucsb.edu/lod/ontology/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?state ?sudoknElectroplaters ?epaFacilities WHERE {
  {
    SELECT ?state (COUNT(DISTINCT ?company) AS ?sudoknElectroplaters) WHERE {
      GRAPH <https://purl.org/okn/frink/kg/sudokn> {
        ?company s:hasPrimaryNAICSClassifier <http://asu.edu/semantics/SUDOKN/NAICS%20332813-individual> ;
                 s:organizationLocatedIn ?site .
        ?site s:locatedInState/rdfs:label ?state .
      }
    } GROUP BY ?state
  }
  OPTIONAL {
    SELECT ?state (COUNT(DISTINCT ?fac) AS ?epaFacilities) WHERE {
      GRAPH <https://purl.org/okn/frink/kg/fiokg> {
        ?rec frs:ofPrimaryIndustry <http://w3id.org/fio/v1/naics#NAICS-332813> .
        ?fac frs:hasRecord ?rec ; kwgo:sfWithin ?reg .
      }
      FILTER(STRSTARTS(STR(?reg),'http://stko-kwg.geog.ucsb.edu/lod/resource/administrativeRegion.USA.'))
      FILTER(STRLEN(REPLACE(STR(?reg),'^.*administrativeRegion[.]USA[.]',''))=5)
      BIND(SUBSTR(REPLACE(STR(?reg),'^.*administrativeRegion[.]USA[.]',''),1,2) AS ?stFips)
      GRAPH <https://purl.org/okn/frink/kg/spatialkg> {
        ?st a kwgo:AdministrativeRegion_1 ; kwgo:hasFIPS ?stFips ; rdfs:label ?state .
      }
    } GROUP BY ?state
  }
} ORDER BY DESC(?sudoknElectroplaters) LIMIT 12
