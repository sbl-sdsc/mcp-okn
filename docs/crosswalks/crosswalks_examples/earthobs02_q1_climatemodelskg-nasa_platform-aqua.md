**The timeout, and the fix.** The query selected the platform with

```
?p a cpub:Platform ; cpub:name ?pn . FILTER(LCASE(STR(?pn)) = "aqua")
```

which binds every platform name in climatemodelskg and lowercases each one before comparing. climatemodelskg has grown roughly 5.6× since this transcript was written, and that filter grew with it. Checking the stored value first shows the name is held as exactly `"Aqua"`, so the filter becomes a bound literal — `cpub:name "Aqua"` — and the query returns immediately. The same applies to the NASA side's `FILTER(STR(?nl) = "Aqua")`.

This is worth stating as a rule: **`LCASE`/`STR` equality filters are lookups written in a form the engine cannot index.** Confirm the stored casing once, then bind it.

**Why the join is required.** climatemodelskg knows a paper *mentioned* a platform but nothing about what flies on it; nasa-gesdisc-kg holds the GCMD platform-instrument hierarchy but no literature. Only the name join connects "this platform is discussed in the climate-modelling literature" to "here is its instrument payload."

**Ranking the crosswalk by instrument count surfaces categories, not platforms.** The top entries — `GROUND STATIONS` (202), `AIRCRAFT` (53), `Ships` (35), `Airplane` (24), `METEOROLOGICAL STATIONS` (24) — are GCMD *container terms*, not vehicles. They accumulate instruments because every ground-based or airborne instrument in the vocabulary hangs beneath them. The genuine platforms in the list are the aircraft (DC-8, ER-2, P-3B, WB-57F, C-130, Global Hawk), and **no satellite appears in the top twelve at all** — Aqua, a real orbiting platform, carries 12 instruments and ranks far below `GROUND STATIONS`.

So instrument count is a measure of **vocabulary position**, not of mission capability, and the crosswalk's 302 shared names include a substantial share of generic terms that will match trivially. A free-text mention of "aircraft" in a paper is not evidence that the paper discusses a NASA platform. The join is sound for specific named platforms like Aqua and the DC-8; it should not be aggregated across all 302 without filtering the container terms out first.

**One data note.** Aqua's instrument list includes the literal string `NOT APPLICABLE`, a GCMD placeholder rather than an instrument. It is reproduced verbatim above; any count of "instruments per platform" taken from this vocabulary will be inflated by one wherever that placeholder appears.
