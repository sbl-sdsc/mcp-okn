Crosswalk: biomarkerkg × spoke-okn on Entrez. BiomarkerKG encodes its gene analytes as PubChem RDF gene IRIs — and the GID number IS the NCBI Gene (Entrez) id, so `GID10082` is Entrez 10082. That makes this an Entrez join wearing a different IRI, and it puts BiomarkerKG on the federation's largest gene cluster for the first time.

Research question: for a gene whose level BiomarkerKG treats as a biomarker, what does SPOKE add — the disease associations and compounds of that same gene?

---

🧠 **Assistant**

SPOKE contributes two things BiomarkerKG has no notion of: a gene's **disease-association breadth** (`ASSOCIATES_DaG`) and the **compounds that regulate it** (`UPREGULATES_CuG` / `DOWNREGULATES_CdG`).

**Why this answers the question.** The ranking splits BiomarkerKG's gene analytes into two kinds. The top of the list is **inflammatory cytokines** — IL6, IFNG, TNF, TGFB1, IL10, CRP — associated with 34–54 diseases each and regulated by *no* compound in SPOKE. These are non-specific systemic markers: they move in almost everything, which is exactly why they are measured, and exactly why a high disease count is a warning about specificity rather than a recommendation. The other kind is **oncogenes and drug targets** — PIK3CA, TP53, BRAF, EGFR, ERBB2, MYC — with fewer associations but non-zero compound regulation, i.e. a pharmacological handle.

That compound column is the actionable one, and it exists only because of the join: BiomarkerKG says a gene is measurable, SPOKE says something can move it.

**Worked example.** BRAF, a BiomarkerKG analyte, carries 33 SPOKE disease associations spanning far beyond its canonical oncology role — biliary tract, breast, colon, colorectal, kidney, lung cancer, glioblastoma, leukemia and multiple myeloma, but also atopic dermatitis, cardiomyopathy, depressive disorder, diabetes mellitus, epilepsy, hypertension and myopia. A biomarker's disease *breadth* in SPOKE is a direct read on how much specificity to expect from it.

**Caveats.** (1) `ASSOCIATES_DaG` is an aggregated association edge of mixed provenance and strength — count it as breadth, not as evidence weight. (2) A compound count of 0 means SPOKE records no regulatory compound, not that none exists. (3) The Entrez identity rests on PubChem's GID equalling the NCBI Gene id; spot-checked here via GID10082 = glypican 6 = Entrez 10082.

```sparql
PREFIX obo: <http://purl.obolibrary.org/obo/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX spoke: <https://purl.org/okn/frink/kg/spoke-okn/schema/>
SELECT ?geneSymbol (COUNT(DISTINCT ?disease) AS ?spokeDiseaseAssociations)
       (COUNT(DISTINCT ?compound) AS ?spokeRegulatingCompounds) WHERE {
  { SELECT DISTINCT ?ez WHERE {
      GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
        VALUES ?bp { obo:OBCI_1000009 obo:OBCI_1000015 obo:OBCI_1000016 obo:OBCI_1000017 }
        ?s ?bp ?g . FILTER(STRSTARTS(STR(?g),'https://pubchem.ncbi.nlm.nih.gov/rest/rdf/gene/GID')) }
      BIND(REPLACE(STR(?g),'^.*/gene/GID','') AS ?ez) } }
  BIND(IRI(CONCAT('http://www.ncbi.nlm.nih.gov/gene/',?ez)) AS ?gg)
  GRAPH <https://purl.org/okn/frink/kg/spoke-okn> {
    ?gg rdfs:label ?geneSymbol .
    OPTIONAL { ?disease spoke:ASSOCIATES_DaG ?gg }
    OPTIONAL { { ?compound spoke:UPREGULATES_CuG ?gg } UNION { ?compound spoke:DOWNREGULATES_CdG ?gg } }
  }
} GROUP BY ?geneSymbol ORDER BY DESC(?spokeDiseaseAssociations) LIMIT 15
```
