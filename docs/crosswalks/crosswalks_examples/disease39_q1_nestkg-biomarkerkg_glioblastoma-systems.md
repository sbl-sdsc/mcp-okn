**At NeST's exact tumour-subtype terms, BiomarkerKG's markers are essentially all dbSNP variants — 3,334 of them, against 1 PubChem gene and 1 other.** Not a single UniProt protein. So the literal form of the question — "do those biomarkers fall inside the implicated systems?" — has the answer **no, and it cannot**: system membership is defined over proteins, and at these MONDO terms there are no protein markers to place. A query that joins the two graphs' proteins at the same cancer term returns zero rows, which is a *vocabulary* result, not a biological one.

That is a textbook glioblastoma profile recovered from mutation data alone — RTK/EGFR signalling on top, then PI3K-AKT, then CDK and p53 — and it is exactly the context a biomarker list lacks.

**So how do you actually connect them?** Through the **variant** axis, not the protein axis. BiomarkerKG's glioblastoma markers are 152 rsIDs; ProKN carries 68,695 rsIDs on its UniProt natural-variant annotations (crosswalk **V2**, 3,241 shared with BiomarkerKG), and those annotations name the protein. The route is BiomarkerKG rsID → ProKN variant → UniProt protein → NeST system — three joins, of which this crosswalk is the last. Attempted here as a single federated query it returned no rows, so it is offered as the route to develop, not a verified result.

**Two things to carry away.** (1) This crosswalk's real use is *cohort-level*: it tells you which of NeST's cancers BiomarkerKG covers at all, and with what kind of marker. (2) The same lesson as D39-Q2's false zero on breast carcinoma — a direct MONDO-to-MONDO join between these graphs is sensitive to which term each side files against, so check the analyte class and the term granularity before reading a zero as an absence.

#### Query 1

_2026-09-02T05:01:22+00:00 · `nestkg`, `ubergraph`, `biomarkerkg`_

```sparql
PREFIX obo: <http://purl.obolibrary.org/obo/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX blv: <https://w3id.org/biolink/vocab/>
SELECT ?cancerLabel ?analyteClass (COUNT(DISTINCT ?entity) AS ?analytes) WHERE {
  GRAPH <https://purl.org/okn/frink/kg/nestkg> { ?a blv:object ?mondo }
  GRAPH <https://purl.org/okn/frink/kg/ubergraph> { ?mondo rdfs:label ?cancerLabel }
  GRAPH <https://purl.org/okn/frink/kg/biomarkerkg> {
    VALUES ?dp { obo:OBCI_1000002 obo:OBCI_1000006 obo:OBCI_1000008 obo:OBCI_1000003 }
    ?bm ?dp ?mondo .
    VALUES ?bp { obo:OBCI_1000009 obo:OBCI_1000015 obo:OBCI_1000016 obo:OBCI_1000017 }
    ?bm ?bp ?entity .
  }
  BIND(IF(CONTAINS(STR(?entity),'/snp/rs'),'dbSNP variant',
       IF(CONTAINS(STR(?entity),'purl.uniprot.org'),'UniProt protein',
       IF(CONTAINS(STR(?entity),'rdf/gene/GID'),'PubChem gene',
       IF(CONTAINS(STR(?entity),'pubchem.ncbi.nlm.nih.gov/compound'),'PubChem compound','other')))) AS ?analyteClass)
  FILTER(?cancerLabel != "cancer")
} GROUP BY ?cancerLabel ?analyteClass ORDER BY ?cancerLabel DESC(?analytes)
```
