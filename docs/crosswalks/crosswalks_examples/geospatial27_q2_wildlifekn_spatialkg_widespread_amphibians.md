**Same break, same fix.** This query inherited the county-name extraction from Q1: `REPLACE(?rl,'^.*, ([^,]+ County), Florida.*$','$1')`, a pattern that needs a comma *before* the county name. SpatialKG's labels are two-part (`Alachua County, Florida`), so the regex never matched, `REPLACE` returned the label unchanged, and `?county = ?cname` was false on every row — zero results, no error. Building the SpatialKG label with `CONCAT(?county, ', Florida')` instead resolves it.

**Why this answers the question.** Every one of the top twelve is an **amphibian**, and they are the species a Florida herpetologist would name: the southern toad (*Anaxyrus terrestris*) in 55 of 62 counties, the green and squirrel treefrogs (*Hyla cinerea*, *H. squirella*), the southern leopard frog (*Lithobates sphenocephalus*), the eastern narrow-mouthed toad, oak toad, pine woods treefrog, southern cricket frog, barking treefrog and pig frog. That the ranking is amphibian-only reflects Wildlife-KN's calling-survey origin — these are species detected by breeding call, which is a method that covers counties evenly rather than following birders.

**The finding worth pulling out: two of the seven most widespread species are introduced.** *Eleutherodactylus planirostris* (greenhouse frog, 38 counties) and *Osteopilus septentrionalis* (Cuban treefrog, 36) are non-native invasives, and they are now more widely recorded than most native treefrogs — the Cuban treefrog ties the oak toad and pine woods treefrog exactly. A ranking built only to answer "what is most widespread" surfaces an invasion front as a side effect, which is the kind of result the join is worth making for.

**A caution on the denominator.** 62 counties is Florida's full complement, so *Anaxyrus terrestris* at 55 is near-saturation and the top of this list is compressed — the difference between 36 and 38 counties is not a meaningful gap in range. The lower half of the table discriminates better than the top.

#### Query 1

```sparql
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX wk: <https://wildlife.proto-okn.net/kg/>
PREFIX kwgo: <http://stko-kwg.geog.ucsb.edu/lod/ontology/>
SELECT ?speciesLabel (COUNT(DISTINCT ?county) AS ?floridaCounties) WHERE {
  {
    SELECT DISTINCT ?county WHERE {
      { SELECT DISTINCT ?county WHERE {
          GRAPH <https://purl.org/okn/frink/kg/wildlifekn> { ?loc a wk:Location ; rdfs:label ?county . }
          FILTER(STRENDS(STR(?county),'County')) } }
      GRAPH <https://purl.org/okn/frink/kg/spatialkg> {
        ?reg a kwgo:AdministrativeRegion_2 ; rdfs:label ?sc .
      }
      FILTER(STR(?sc) = CONCAT(STR(?county), ', Florida'))
    }
  }
  GRAPH <https://purl.org/okn/frink/kg/wildlifekn> {
    ?loc2 a wk:Location ; rdfs:label ?county .
    ?obs rdf:object ?loc2 ; rdf:subject ?species .
    ?species rdfs:label ?speciesLabel .
  }
} GROUP BY ?speciesLabel ORDER BY DESC(?floridaCounties) LIMIT 12
```
