**Why the join is required.** AOP-Wiki says *which* chemicals are AOP stressors but holds no assay data; ToxCast holds assay and activity data but does not know which chemicals are AOP stressors. Only the CAS join connects "is an AOP stressor" to "how heavily screened, and how often active." AOP-Wiki encodes CAS as `https://identifiers.org/cas/…` and ToxCast as `http://…`, so the join applies an http(s) rewrite.

**The timeout, and the one-token fix.** The activity query filtered hit calls with

```
?hit sio:SIO_000300 ?v . FILTER(STR(?v) = "1.0")
```

which binds *every* hit-call value in ToxCast and then tests it as a string. The values are stored as plain `xsd:string` literals, so the filter can be replaced by a **bound literal lookup**:

```
?hit sio:SIO_000300 "1.0" .
```

Same semantics, but the engine can go straight to the matching triples instead of scanning and filtering. That alone takes the query from a 280-second timeout to an immediate answer. It is the same lesson as the FILTER-inside-GRAPH cases elsewhere in this corpus: if a filter is testing equality against a constant, it is not a filter, it is a lookup written the slow way.

**Why this answers the questions — and why the two rankings must not be conflated.** Coverage and activity are different measurements and they reorder the same chemicals. PFOS leads on **coverage** (1,510 endpoints) but Triclosan leads on **activity** (537 active). Bisphenol A is second on coverage and last of these six on activity.

The ratio is the informative quantity. Triclosan is active in **41%** of its endpoints (537/1,316), PFOS in **32%** (480/1,510), Bisphenol A in **27%** (375/1,414). Coverage measures how much regulatory attention a chemical has received; the active fraction measures how promiscuously it perturbs *in vitro* biology. A chemical can top the coverage table purely because it is politically salient.

The stressor list itself is coherent as toxicology: PFOS and Triclosan (persistent consumer-product chemicals), Bisphenol A and Diethylstilbestrol (canonical endocrine disruptors — DES being the historical human teratogen), and a block of pesticides (Mancozeb, Maneb, Cypermethrin, Cyfluthrin, Prochloraz, Endosulfan, Methyl parathion, Emamectin). These are the chemicals with enough mechanistic literature to anchor an AOP *and* enough regulatory interest to be screened across the full ToxCast battery.

**One caution on the Q2 scope.** The six chemicals in the activity query are named explicitly rather than discovered, so that table is a comparison among a chosen set, not a ranking of all AOP stressors by activity. The coverage query (Q1) is unrestricted and does rank.

#### Query 1

```sparql
PREFIX aop: <http://aopkb.org/aop_ontology#>
PREFIX dc: <http://purl.org/dc/elements/1.1/>
PREFIX edam: <http://edamontology.org/>
PREFIX ro: <http://purl.obolibrary.org/obo/>
SELECT ?chem (REPLACE(STR(?cas2),'http://identifiers.org/cas/','') AS ?CAS) (COUNT(DISTINCT ?mg) AS ?nAssayEndpoints) WHERE {
  GRAPH <https://purl.org/okn/frink/kg/biobricks-aopwiki> {
    ?s aop:has_chemical_entity ?cas ; dc:title ?chem .
  }
  BIND(IRI(REPLACE(STR(?cas),'https://identifiers.org/cas/','http://identifiers.org/cas/')) AS ?cas2)
  GRAPH <https://purl.org/okn/frink/kg/biobricks-toxcast> {
    ?t edam:has_identifier ?cas2 ; ro:RO_0000056 ?mg .
  }
} GROUP BY ?chem ?cas2 ORDER BY DESC(?nAssayEndpoints) LIMIT 12
```
