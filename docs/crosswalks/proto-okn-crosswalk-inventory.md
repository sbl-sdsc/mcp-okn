These are pairwise organism overlaps composed **through the ubergraph hub**, so each carries two materialized counts rather than one. `exact_id` = taxa with the identical NCBITaxon id on both sides (symmetric). `clade_a_in_b` / `clade_b_in_a` = how many of the first / second KG's taxa fall under the other's once expanded through ubergraph's `subClassOf*` hierarchy (directional).
